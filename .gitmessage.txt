# Commit Type
####################
# feat     : 새로운 기능 개발 작업
# docs     : 문서 작성·수정 작업
# config   : 개발 환경·프로젝트 설정 작업
# design   : UI·UX 디자인 작업
# style    : 동작 변경 없는 코드 스타일 작업
# refactor : 동작 변경 없는 코드 구조 개선 작업
# test     : 테스트 작성·수정 작업
# chore    : 기타 유지보수 작업
# fix      : 일반 버그 수정 작업
# hotfix   : 치명적 버그 긴급 수정 작업
# build    : 의존성·빌드 구성 작업
# ci       : CI 자동화 작업
# perf     : 성능 개선 작업
